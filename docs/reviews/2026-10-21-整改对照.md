## 一个规格之外的纠正（重要）

评审 P1-1 建议把 `tokenMeter` 从 `inject` 移走，靠 `try/catch` 降级。照做后真机复验发现：
**报告里「平台定价」整块消失**。

原因：Cordis 禁止读取未注入的服务，抛 `cannot get property "tokenMeter" without inject`，
可选链 `ctx.tokenMeter?.measure()` 拦不住，`try/catch` 只能把能力吞掉。
而平台定价正是本插件相对离线 CLI 的**唯一**增量 —— 等于为了消除一个理论风险，
废掉了核心价值。

正解是 Cordis 的 `ctx.get(name)`，官方注释原文：
*Read a service from the store **without the inject requirement**.*

```js
export const inject = ['sessionQuery'];          // 只声明必需
const tm = ctx.get?.('tokenMeter') ?? null;      // 可选读取，缺了返回 undefined
```

两条需求同时满足：缺 tokenMeter 不会卡死激活，有 tokenMeter 就能拿到平台定价。
真机复验：新会话报告重新出现「平台定价」区块（空会话 `baseline.kind = none`，符合预期）。
